# COSMOS - Space Dashboard

COSMOS is a modern, interactive web dashboard designed for space exploration enthusiasts. It aggregates real-time data from space agencies and flight trackers into a unified, visually engaging interface. 

## Overview
The application functions as a central hub for astronomy data, rendering NASA's daily discoveries, detailed planetary insights, and upcoming launch schedules. Built entirely with vanilla web technologies, it focuses on quick execution, responsive layouts, and clean visual feedback during data fetching.

## Key Features
* **NASA APOD Integration:** Displays the Astronomy Picture of the Day with full context and descriptions directly from NASA's API.
* **Planetary Comparison Hub:** A data-driven matrix for reviewing and contrasting essential metrics of planets within our solar system.
* **Live Space Launch Tracker:** Fetches and structures schedules for upcoming global rocket launches.
* **Sleek Asynchronous UX:** Employs skeleton screens during API requests to maintain layout integrity and improve perceived performance.

## Tech Stack
* **Markup:** HTML5
* **Styling:** Tailwind CSS (v4)
* **Logic:** Vanilla JavaScript (ES6+)
* **Data Sources:** REST APIs (NASA APOD, Space Launch APIs)
